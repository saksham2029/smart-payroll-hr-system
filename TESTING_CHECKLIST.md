# Testing checklist
1. Sign in as admin and employee.
2. Add a valid employee and confirm duplicate IDs are rejected.
3. Search and filter the directory.
4. Record attendance and verify it appears.
5. Apply for leave as employee; approve/reject as admin.
6. Run payroll for a month and review history.
7. Print a payslip and use browser Save as PDF.
8. Export the employee CSV.
9. Restart server and verify CSV records persist.
